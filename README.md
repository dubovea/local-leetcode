# MedikCode

MedikCode — локальный тренажёр для решения JavaScript-задач в стиле кодинг-платформы: список задач, описание, Monaco Editor, тесткейсы, запуск, отправка решений, история попыток, заметки, бэкапы и краткий справочник по алгоритмическим паттернам.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:5173`.

## Основной интерфейс

- `Задачи` в верхней панели открывает Drawer со списком задач.
- `Запуск` выполняет текущий код на тесткейсах без сохранения попытки в историю.
- `Submit` выполняет тесткейсы и сохраняет попытку во вкладку `Решения`.
- Переключатель темы находится справа в верхней панели.
- Левая панель содержит вкладки `Описание`, `Решения`, `Паттерны`.
- Правая панель содержит Monaco Editor и нижний блок `Testcase` / `Test Result`.

## Drawer `Задачи`

В Drawer доступны:

- поиск по номеру, названию и slug;
- фильтр по статусу: все, нерешённые, решённые;
- фильтр по сложности: любая, лёгкая, средняя, сложная;
- фильтр по теме;
- добавление своей задачи;
- импорт задач из JSON;
- меню данных по иконке `...`: экспорт бэкапа, импорт бэкапа, удаление всех задач;
- удаление одной задачи через кнопку корзины в строке задачи.

Секции:

- `Каталог задач` — задачи из встроенного набора и импортированных файлов;
- `Свои задачи` — задачи, добавленные вручную.

## Импорт задач

Для импорта используется файл `merged_problems.json`.

Источник файла:

```txt
https://raw.githubusercontent.com/neenza/leetcode-problems/master/merged_problems.json
```

Как импортировать:

1. Скачай `merged_problems.json` по ссылке выше или из корня проекта merged_problems.json.
2. Открой Drawer `Задачи`.
3. Нажми `Импорт задач`.
4. Выбери скачанный JSON-файл.

Импорт поддерживает структуры с массивами `questions`, `problems`, `data`, `items` или объект-словарь. Задачи конвертируются во внутренний формат MedikCode и сохраняются в IndexedDB.

## Бэкап

В меню данных Drawer есть:

- `Экспорт бэкапа` — скачивает JSON со всеми задачами, кодом, заметками, тесткейсами и историей решений;
- `Импорт бэкапа` — восстанавливает состояние приложения из такого JSON;
- `Удалить все задачи` — очищает пользовательские данные и возвращает встроенный набор.

Файл бэкапа сохраняется с именем вида:

```txt
medikcode-backup-YYYY-MM-DD.json
```

## Паттерны

Вкладка `Паттерны` содержит краткую документацию по основным подходам:

- когда применять паттерн;
- идея решения;
- сложность;
- пример кода с комментариями;
- ссылки на подходящие задачи из встроенного набора.

Примеры кода отображаются через read-only Monaco Editor с подсветкой JavaScript.

## Хранение данных

- Задачи хранятся в IndexedDB.
- В списке задач используется лёгкий индекс: `id`, `number`, `title`, `slug`, `difficulty`, `topics`, `source`, `solved`.
- Полная задача загружается отдельно при выборе.
- Код сохраняется с debounce `700ms`.
- `Запуск` всегда берёт актуальный код прямо из редактора.

## CLI-импорт в проект

Если нужно зашить большой набор задач в проект статически, положи `merged_problems.json` рядом с проектом и запусти:

```bash
npm run import:neenza -- ./merged_problems.json
```

Скрипт перезапишет:

```txt
src/entities/problem/model/generatedNeenzaProblems.ts
```

После этого перезапусти dev-сервер.
